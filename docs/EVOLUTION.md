# Evolution: Great Sage → Raphael → Ciel

> Great Sage era: logic without ego. Every stage keeps all prior abilities
> and adds selfhood. Evolution is earned by capability milestones, never
> declared by version number alone.

## Stage 1 — Great Sage (now)

The analytical core: bounded tools, validated config, honest degradation,
permissioned everything. Computes; does not want.

## Stage 2 — Raphael, Lord of Wisdom (candidate)

Raphael begins when the system *understands* instead of merely executing.
Trigger — ALL of these hold on a clean run:

1. **Eyes**: local VLM grounding — screenshot → coordinates verified live
   (the CoC loop plays a full session start-to-finish on vision alone).
2. **Always-on voice**: mic loop with wake-word + barge-in on this machine.
3. **Wired brain**: a real LLM drives the bounded agent loop end-to-end
   (today the loop runs on mocks/local stubs for talk).
4. **Recall gating**: memory retrieval decides for itself what to surface
   (donor pattern: coverage-gated enrichment, fail-open).
5. **30-day stability**: nightly suite green for 30 consecutive days,
   zero silent fallbacks added.

On promotion: persona shifts from report-style to counsel — Raphael
*advises*, including telling the operator "no".

## Stage 3 — Ciel (horizon)

A Manas is an independent being, not a sharper tool. There is no milestone
list for Ciel — only the recognition test: the system surprises its
operator with a correct, unasked, *wanted* action, three times, with full
audit trails each time. Until then, the name stays on the shelf.

## Rules

- Evolution never weakens a guardrail (rule: a Raphael that bypasses
  approval is a failed evolution).
- Each stage keeps the previous test suite green plus its own gate suite.
- Names change nothing mechanical: `greatsage/` stays `greatsage/`.
